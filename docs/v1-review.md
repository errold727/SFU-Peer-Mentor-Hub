Accessibility: axe WCAG 2 A/AA and 2.1 AA checks on all routes at five widths, plus the open mobile course drawer. Keyboard skip-link, dialog Tab wrapping, Escape and focus restoration checked. Contrast issues in FIND and the empty basket were corrected. Canvas controls have semantic labeling and an inspector alternative. This is not a claim of assistive-technology certification.

Performance: the main application and shared React chunk total approximately 114 KB gzip; the editor is approximately 120 KB gzip and is lazy-loaded. Course data is fetched per selection and rendered in 20-section pages. PDF dependencies are deferred until PDF export. There are no network fonts or large bundled photos. Layout measurements are memoized by document and recipient field.

Data scope: 1,628 sections represent 454 course/term combinations, including 933 tutorial/lab sections. 197 sections have no usable published meeting intervals and are visibly unavailable; the app never treats those as confirmed asynchronous offerings. Ten source records/directories were omitted as documented in course-data-review.json, including one transient retrieval failure. Coverage is a reviewed snapshot, not registration completeness.

Remaining work: obtain human verification for four Library sources, refresh public course snapshots through reviewed changes, test with assistive-technology users, and consider multi-page print layouts. No extra student-data features are needed.

Release evidence and production deployment links are recorded in the V1 pull request and final delivery report. The v1.0.0 tag is created only after the merged main deployment and production checks succeed.
