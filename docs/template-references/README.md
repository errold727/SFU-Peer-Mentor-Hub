# Reference pack inventory

All 15 PNGs and README.txt from `SFU_Peer_Mentor_Generic_Poster_Samples.zip` were extracted into `originals/` and individually opened for visual inspection. Originals remain local and are ignored by Git to avoid committing 20 MB of redundant raster references. `manifest.json` records every original filename, byte count and SHA-256; `previews/` contains optimized review copies of all 15.

These supplied images are visual reference material, not authoritative SFU sources or product instructions. Their logos, slogans, phone numbers, dates, course examples, opening hours and immigration wording are not automatically incorporated. Production templates are independent editable block configurations. No original poster is loaded as a canvas background.

Three new, text-free illustrative photo assets are under `public/assets/poster-scenes/`. They were produced using the built-in imagegen tool, then resized/compressed to WebP. They depict generic university settings, not verified SFU buildings or people. The original generated PNGs remain in the local Codex generated-images folder. Prompts are recorded in `image-prompts.json`. The mentor silhouette is a code-native replaceable placeholder, not a person's photograph. No image contains factual template text or an institutional logo.

Reference-to-template mapping and final browser/export evidence are documented in `../TEMPLATE_PACK.md`.
