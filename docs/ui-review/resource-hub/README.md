## Visual observations

All eight screenshots were opened and inspected. Card typography, official-source actions, review warnings, and modal content are readable at the three requested sizes. The mobile native Audience select shortens its selected label to fit, while its options and accessible name remain available.

The review found that an insertion status message retained its clipping warning after the text was manually shortened to fit. A narrow `Poster.tsx` correction now recomputes insertion diagnostics using the current element. The template browser regression verifies the initial warning and its removal after the wording fits; the recaptured screenshot shows the corrected status and “No issues detected.” The workflow preserves the template’s original geometry rather than using Auto Arrange on its dense multi-section layout.

The actual three-card export PNG and the PDF rendered with bundled Poppler were both opened and inspected at 816 × 1056. No text is clipped or overlapped. The Surrey room, check-hours condition, undergraduate-only WriteAway wording, booking/uncertainty notices, both fee dates, undergraduate restriction, processing-time advice and provider names are visible in both outputs. Auto Arrange fit the original three resource bodies on Letter; no resource facts or conditions were removed to make that export fit. The PDF raster is stored in ignored `.course-import/resource-hub-three/resource-poster-pdf-render.png`.

## Reproduce screenshots

Set `RESOURCE_REVIEW_CAPTURE=1` before running `npx playwright test e2e/resource-hub.spec.ts --workers=1`. Without this environment variable, the tests do not write documentation images. Playwright’s configuration builds and previews locally unless `PLAYWRIGHT_BASE_URL` is provided. The resource scenarios freeze the displayed date at the catalog’s review date so term filtering is deterministic; they do not assert that published dates remain current indefinitely.
